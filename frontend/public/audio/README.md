# Folder Audio Soundtrack Game

Letakkan file lagu soundtrack **"Taklukan Langit"** di folder ini (`public/audio/`).

### File yang Didukung:
1. `taklukan_langit.mp3` *(Sangat Direkomendasikan)*
2. `taklukan_langit.ogg` *(Opsional untuk web / seamless looping)*
3. `taklukan_langit.wav`

---

### Jalur File di Web:
Setelah file dimasukkan, musik akan dimuat secara otomatis dari:
- `/audio/taklukan_langit.mp3`

> **Catatan:** Jika file belum dimasukkan, game secara otomatis menggunakan **Web Audio API Synth Fallback** dengan nada melodi petualangan langit agar game tetap bersuara!
